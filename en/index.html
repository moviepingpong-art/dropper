About

What is Dropper

“Just drop in a file, and the hassle is handled.” We call these little tools Dropper, and we build and release them as a series. The first one reads an event document, adds the date and venue to Google Calendar, and even writes the WhatsApp/SNS announcement for you. They all work the same way — just drop — so anyone can use them, not only a particular group or sport. More tools will be added over time.
