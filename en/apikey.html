AI mode runs on your own API key. "API key" sounds technical, but all you do is press one button on Google's own page and copy the text it gives you.

What an API key is

It is a spare key that lets Gemini be called from your own Google account. Dropper borrows that key to ask the AI, on your behalf, to read the file you dropped.

The key stays yours. Dropper never holds it for you — it sits inside your browser only. You can regenerate it or throw it away on Google's side at any time.

It is not the same as pasting a question into the official chat window.

Why there is nothing to worry about on cost

Getting an API key in Google AI Studio does not involve entering any payment details.

  • 💳 No credit card screen ever appears. You start using it while there is simply no way to bill you.
  • 🆓 The free tier is roughly 1,500 requests a day. One file read is one request, so personal use rarely comes close.
  • 🛑 Going over the limit stops the requests — it does not charge you. For the rest of that day you can use standard mode without AI, and the free tier resets the next day.

Where the key you type actually goes

Dropper has no server. Here is exactly where your key goes.

ItemHow it actually works
Where the key is storedOnly on your own device (your browser's localStorage). It is not synced to your other devices either.
Our serverThere isn't one. We cannot receive your key, or anything that was read from your file.
Where the key is sentTo Google's Gemini API only, and only to ask — with your key — that your own file be read.
If you want to stopClearing your browser data removes the key. Deleting the key in Google AI Studio disables it immediately.

Three steps to get your key

If you have a Google account, you need nothing else.

1Open Google AI Studio

Use the button below to open Google's own page (aistudio.google.com). This is Google's site, not ours.

2Sign in with your Google account

Sign in with the Google account you normally use. You will not be asked for payment details here.

3Press "Create API key" and copy it

A string starting with "AIza…" appears. Copy it, paste it into Dropper's API key field, and you're done.

Open Google AI Studio ↗

※ Keep your key to yourself. If someone does see it, delete that key in AI Studio and create a new one — the old key stops working.

Common worries

Could I be charged without noticing?
There is no credit card on file, so there is no way to bill you. Going past the free tier stops that day's requests rather than charging you.
What if my key is stolen?
The key sits on your device only and is never sent to our server. If you are still uneasy, delete the key in Google AI Studio — it stops working the moment you delete it, and you can create a new one.
If I use up the free tier, does the tool stop working?
No. Standard mode, which does not use AI, keeps working. AI mode gets its free tier back the next day.
Can I use it on confidential documents?
On the free tier, what you send may be used to improve Google's services. Please do not put confidential documents through AI mode (standard mode sends nothing outside).
Is the tool unusable without an API key?
No. Standard mode works from the start with no key at all. AI mode is an extra option for people who want the reading to be more accurate.
