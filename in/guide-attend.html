Yahan se shuru karein

1. Attendance kya hai

Practice, tournament aur doosre events ke jawab jama karke ginne ka web tool. Organiser group banata hai, members ko roster mein daalta hai, aur ek attendance link baant deta hai. Members us link ko kholte hain, roster se apna naam chunte hain, aur yes, maybe ya no tap kar dete hain.

Har group ke liye ek hi link hota hai. Naya event jodne par bhi wo nahi badalta, isliye group chat mein ek baar pin kar dijiye. Baar-baar naya link baantne ki zaroorat nahi.

Series ke chaar tools mein se sirf Attendance mein hum aapka data rakhte hain. Alag-alag device se kai log likhte hain aur sabko ek hi result dikhna hota hai, isliye yeh akele browser ke andar nahi ho sakta. Hum kya rakhte hain aur use kaise delete karna hai, wo privacy policy mein likha hai.

Yeh tool abhi preview mein hai. Screens aur steps badal sakte hain.

3. Organiser ko kya karna hai

1Group banayein

Attendance ka admin screen kholein, “Naya group banayein” ke neeche group ka naam aur members ke naam bharein, aur “Isi se banayein” dabayein. Sirf naam bhi kaafi hai.

Spreadsheet ya text file ka roster “≡ List paste karein” se ek saath ja sakta hai. Ek line mein ek aadmi. Gender aur note bhi daal rahe hain to tab ya comma se alag karein.
Ek switch hai: “Members ko bhi dikhayein ki kaun 〇, △ ya × hai”. Use band karne par members ko sirf ginti dikhti hai, gender ke hisaab se. Admin screen par aapko naam dono haalat mein dikhte hain, kyunki team chunne ke liye wo chahiye. Baad mein badal sakte hain.

2Admin link save karein (zaroor)

Group ban jaane par admin link sirf ek baar dikhta hai. Wahi aapki chaabi hai, aur screen band karne ke baad dobara kabhi nahi dikhega.

⚠️ Admin link kho gaya to roster aur sabke jawab hamesha ke liye chale jayenge. Chaabi khud hamare server par nahi rakhi jaati, isliye poochne par bhi hum bhej nahi sakte. Screen par “Copy” dabayein aur bookmark ke URL field mein paste karein, ya khud ko message kar dein.

Sirf address bar ko bookmark na karein. Chaabi wala hissa chhoot sakta hai. Hamesha screen ke “Copy” button ka istemal karein.

3Event add karein

Admin screen par “Event se attendance banayein” ke neeche event add karein. “+ Haath se daalein” se event ka naam, date, last date, jagah aur entries bhar sakte hain. Event ka document ho to use Event Dropper se le aa sakte hain (section 6).

Do last date hoti hain. Ek wo jab tak tournament mein entry bhejni hoti hai. Members ko jawab kis din tak dena hai, wo usi se peeche ginkar apne aap tay hota hai - default saat din pehle. Jawab “jawab ki last date” par band hote hain, aur kitne din peeche rakhna hai wo aap badal sakte hain.

4Attendance shuru karein aur link baantein

“Is event ki attendance shuru karein” dabate hi jawab aane lagte hain. Bas attendance link members ko de dijiye.

Har group ke liye ek hi link, aur wo kabhi nahi badalta. Group chat mein pin kar dijiye, members jab chahein khol lenge. Naya event jodne par naya link baantna nahi padta.

5Dekhein kitna aaya

Admin screen ka “Sabke jawab” har entry ki ginti dikhata hai, aur yeh bhi ki kaun yes, maybe ya no hai. Members ne jo baat likhi ho, wo bhi yahin dikhti hai.

Jinhone abhi jawab nahi diya, unke naam sirf is admin screen par aur officers wale viewing link par dikhte hain. Members ko kabhi nahi. Kisse jaakar poochna hai, wo yahan se pata chalta hai.

4. Teen link, teen kaam

Attendance mein teen link hain aur teenon ka kaam alag hai. Kaunsa kisko dena hai, yeh mat gadbadaiye.

5. Members ko kya dikhta hai

Mila hua link kholte hi neeche teen tab aa jate hain. Na kuch install karna, na account banana.

Jawab

Pehli baar member roster se apna naam chunta hai aur “Yeh main hoon” dabata hai. Yeh us device par sirf ek baar hota hai. Uske baad khule hue event dikhte hain, aur har entry par yes, maybe ya no chunkar bhej dete hain. “Ek baat (optional)” mein likh sakte hain, jaise “30 minute late aaunga” ya “do gaadi la sakta hoon”.

Last date se pehle jitni baar chahein jawab badal sakte hain. Galat dab jaane se kuch bigadta nahi.

Mere jawab

Us member ne kis event mein kya jawab diya, uski poori list - aur jo abhi baaki hain wo bhi.

Sabke jawab

Har entry ki ginti, gender ke hisaab se. Jin groups mein organiser ne naam dikhane chune hain, wahan yeh bhi dikhta hai ki kaun yes, maybe ya no hai. Jinhone jawab nahi diya, unke naam members ko kabhi nahi dikhte.

6. Event Dropper se attendance shuru karna

Event ka document PDF ya photo mein ho to pehle Event Dropper se padhwa lein aur wahin se attendance shuru karein. Event ka naam, date, jagah aur last date sab apne aap aa jate hain.

  1. Event Dropper se document padhwayein aur card dekh lein.
  2. “🙋 Attendance par jayein” dabayein. Admin screen khulega, event pehle se aaya hua.
  3. “Isi se attendance shuru karein” dabayein. Jawab shuru ho jate hain aur aap Event Dropper par wapas aa jate hain.
  4. Attendance link announcement mein aa jata hai, group chat par bhejne ke liye taiyaar.
Naye device par pehle admin link paste karke apna group kholein. “Is device par yaad rakhein” dabate hi agli baar paste nahi karna padega. Share kiye ja rahe device par yeh mat karein - us device ko chalane wala koi bhi wahi sab kar sakega jo aap karte hain.
Document ki zaroorat hi nahi hai. Sirf attendance leni ho to pehli screen ke “🙋 Sirf attendance jama karein” se shuru karein.

7. Aksar poochhe jaane wale sawaal

Kya members ko app install karna padega
Nahi. Wo link browser mein kholte hain. Na account banana hai, na kahin sign-in karna hai.
Kya organiser ko Google account chahiye
Attendance ke liye nahi. Sign-in sirf Event Dropper ki taraf maanga jata hai, jab document padhwate hain ya calendar mein kuch daalte hain.
Mera admin link kho gaya
Maafi chahte hain, wo wapas nahi mil sakta. Chaabi khud hamare server par nahi hoti - hoti, to hum aapka roster aur jawab padh sakte the. Group dobara banayein aur naya link baant dein.
Naye phone par wahi group khul jayega
Haan, agar admin link save kiya hai: admin screen ke “Pehle se group hai?” mein paste kar dein. Agar Event Dropper mein Google se sign-in kiya tha, to chaabi aapki apni Google Drive mein rakhi hai - naye device par sign-in karte hi wapas aa jati hai.
Har event ke liye naya link baantna padega
Nahi. Har group ke liye ek hi attendance link hai aur wo kabhi nahi badalta.
Koi member club chhod de to
“Group ka naam aur members” mein us aadmi ke note mein “left” likhkar save kar dein. Wo roster se hat jayega.
Last date ke baad bhi jawab de sakte hain
Nahi. Jawab “jawab ki last date” par band ho jate hain. Use admin screen ke “Jawab ki last date badlein” se aage-peeche kar sakte hain. Result baad mein bhi dikhta rehta hai.
Data delete kaise karein
Admin screen ka “Yeh group delete karein” roster, events aur sabhi jawab hata deta hai. Yeh wapas nahi ho sakta, aur baante hue link khulna band ho jate hain.
Kya iska paisa lagta hai
Nahi, aur koi ad bhi nahi hai.

8. Kuch kaam na kare to

Tools free hone ke kaaran hum one-on-one support nahi dete. Kuch kaam na kare to is page ke steps ek baar phir dekh lein. Koi member kahe ki link theek nahi hai, to aksar URL ka kuch hissa kat gaya hota hai - admin screen ke “Attendance link” se use dobara copy karke bhej dein.
