Privacy Policy

Effective: 15 July 2026 / Last updated: 19 July 2026

DROPPER poori tarah aapke browser mein chalta hai. Hamara koi server nahi hai, aur hum aapka data kabhi collect, store ya transmit nahi karte.

1. Operator

  • Operator: Shigeyoshi (independent developer)
  • Contact: movie.pingpong@gmail.com

2. Hamara approach

DROPPER sirf aapke browser mein chalta hai. Jo bhi padha jaata hai aur jo file aap drop karte hain, wo kabhi hamare server par nahi jaati — hamara server hai hi nahi. Sab kuch aapke apne Google account ke andar hota hai.

3. Google user data kaise handle hota hai

Aapki permission se, DROPPER neeche diye gaye scopes ke andar Google services access karta hai.

ScopeKyun zaroori hai
Google Calendar events banana aur edit karna
(calendar.events)		Aapke event document ya schedule se padhi gayi dates ko aapke apne calendar mein add karne ke liye.
Is app ki banayi files ka access
(drive.file)		Event document ya schedule ka text padhne (OCR) aur usse aapke apne Google Drive mein save karne ke liye.
App-specific data folder
(drive.appdata)		Yaad rakhne ke liye ki files kis folder mein save hoti hain, taaki aapke alag-alag devices (phone, computer) par wahi folder use ho.
  • Ye saara data aapke apne Google account ke andar process hota hai. Hum ismein se kuch bhi receive nahi karte.
  • drive.file sirf un files tak limited hai jo ye app khud banata hai. Ye aapki baaki Google Drive nahi dekh sakta.
  • Text recognition (OCR) ke liye banayi gayi temporary files, text padhte hi turant delete kar di jaati hain.

4. AI feature (Gemini) ke baare mein

AI feature use karne par, aapke event document ya schedule se padha gaya text — ya file khud (PDF ya image) — Google ke Gemini API ko bheja jaata hai. Ye feature use karna hai ya nahi, ye poori tarah aapki choice hai.
  • AI use karna opt-in hai. Sign in ke baad ek dialog aapse "AI use karein" ya "AI use na karein" chunne ko kehta hai.
  • Sirf tab jab aap "AI use karein" chunte hain, event document ya schedule ka text — ya file khud (PDF ya image) — Google ke Gemini API ko bheja jaata hai.
  • Request aapki khud ki li hui API key use karti hai. Key sirf aapke device par (browser ke localStorage mein) store hoti hai aur hamein kabhi nahi bheji jaati.
  • Gemini API ko bheje gaye data ka handling Google ki apni policies ke hisaab se hota hai.
  • Agar aap "AI use na karein" chunte hain, to koi bhi text aapke browser aur aapke apne Google account ke bahar nahi jaata.

5. Data Sharing aur Third-Party Disclosure

DROPPER aapke Google user data ko hamare ya kisi third party ko na bechta hai, na share karta hai, na transfer karta hai. DROPPER ka koi server nahi hai, isliye yeh data hum tak pahunchta hi nahi.

  • Sirf ek exception hai — jab aap "Use AI" choose karte hain. Tabhi event document ya schedule se padha gaya text — ya file khud (PDF ya image) — aapke apne API key se Google ke Gemini API ko bheja jaata hai. Yeh aapke choice par, aapke aur Google ke beech direct transmission hai, hamare through nahi jaata.
  • Gemini API ko bheje gaye data ka handling Google ki Privacy Policy ke according hota hai.
  • Iske alawa, hum Google user data kisi bhi advertiser, analytics provider ya third party ko kabhi disclose nahi karte.

6. Data Protection

DROPPER aapke data ko protect karne ke liye yeh mechanisms use karta hai:

  • Saara communication encrypted connection (HTTPS) par hota hai.
  • DROPPER ka koi server nahi hai, isliye aapka data hamare control mein kabhi store nahi hota aur hamari taraf se external breach ka target nahi banta.
  • Aapki Gemini API key aur settings sirf aapke device (browser ke localStorage) mein store hoti hain, aur hume ya kisi aur ko kabhi transmit nahi hoti.
  • Google services aur Gemini API tak saari access aapke apne Google account ke authentication aur authorization ke tehat hoti hai.

7. Data Retention aur Deletion

DROPPER ka koi server nahi hai, isliye hum aapka koi bhi Google user data retain nahi karte. Sirf yeh information aapke device (browser ke localStorage) mein store hoti hai, aur hum use access nahi kar sakte:

  • AI feature use karna hai ya nahi, yeh choice
  • Aapki Gemini API key (sirf tab jab aapne AI use karna choose kiya ho)
  • Destination folder ki information

Yeh data aap kabhi bhi in tareekon se delete kar sakte hain:

  • Text recognition (OCR) ke liye temporarily banayi gayi files padhne ke turant baad delete ho jaati hain.
  • Google Calendar mein banaye gaye events aur Google Drive mein save ki gayi event documents ya schedules aap khud manage karte hain aur kabhi bhi Google se delete kar sakte hain (DROPPER mein delete function nahi hai).
  • Device par store ki gayi API key aur settings ko aap kabhi bhi apne browser settings se delete kar sakte hain.
  • DROPPER ki aapke Google account tak access ko aap kabhi bhi apni Google Account security settings se revoke kar sakte hain.

8. Pricing

DROPPER abhi free hai, aur hum koi payment information collect ya store nahi karte. Agar aage chalkar paid features aate hain, to ye policy revise ki jayegi aur badlav announce kiya jayega.

9. Google API Services User Data Policy ka Compliance

DROPPER dwara Google APIs se mili information ka use aur transfer, Google API Services User Data Policy ka palan karta hai, jisme Limited Use requirements shamil hain.

10. Is Policy mein Changes

Is policy mein koi bhi badlav isi page par post kiya jayega. Agar badlav important hoga, to tool ke andar bhi announce kiya jayega.

11. Analytics

Dropper service improve karne ke liye site usage samajhne hetu yeh tools use karta hai. Yeh site browsing ke statistical information handle karte hain aur aapke Google Calendar ya Drive ke contents (Google user data) se unrelated hain.

  • Google Analytics: page views aur referrers jaise statistics cookies use karke collect karta hai. Collect ki gayi information anonymized usage statistics hai aur kisi vyakti ko identify nahi karti. Data Google ki Privacy Policy ke according handle hota hai.
  • Visitor counter (hits.sh): page views ki ginti karke dikhata hai. Yeh cookies use nahi karta.
  • Agar aap cookies allow nahi karna chahte, to browser settings mein unhe disable karein ya Google Analytics Opt-out Add-on use karein.
