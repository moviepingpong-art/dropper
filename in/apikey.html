3 step mein key lein Google AI Studio kholein ↗

AI mode aapki khud ki API key par chalta hai. "API key" sunkar mushkil lagta hai, par karna sirf itna hai: Google ke official page par ek button dabayein aur jo text mile use copy kar lein.

API key kya hoti hai

Yeh ek duplicate chaabi hai, jisse aapke Google account se Gemini ko call kiya jaata hai. Dropper wahi chaabi udhaar leta hai aur aapki taraf se AI se kehta hai ki "yeh file padho".

Chaabi aapki hi rehti hai. Dropper use apne paas nahi rakhta — wo sirf aapke browser ke andar rehti hai. Google ki taraf se aap use jab chahe naya bana sakte hain ya delete kar sakte hain.

API key se kya kar paayenge

AI aksar sirf "sawaal poochne ka tool" banke reh jaata hai. API key ke saath wo aisa tool ban jaata hai jise poora kaam saunp sakte hain — padhne se lekar register karne tak.

📥

Ek sheet se sau-do sau entries, ek saath

Schedule Dropper ne ek school year planner se 157 events padhe aur seedha Google Calendar mein daal diye. Chat mein paste karke ek-ek line likhne ka kaam poora khatam.

🎛️

Aapke kaam ke hisaab se bana screen

Naam, date, venue aur deadline alag-alag field mein nikalte hain, to register karne se pehle wahi theek kar sakte hain. Yeh ek dedicated tool hi kar sakta hai, official chat nahi.

🆓

Bekaar padi free tier ko kaam pe lagaiye

Aapke Google account ke saath ek free tier aati hai jise zyaadatar log kabhi use hi nahi karte. API key wahi khol deti hai. Yahan pay-per-use metering nahi hai, is liye use karne se koi charge nahi banta. Jis AI se aap sirf sawaal poochte the, wo ab aapke documents padhkar entries register kar dega.

Paise ki chinta kyun nahi hai

Google AI Studio se API key lene mein payment details daalne ki koi step nahi hai.

  • 💳 Credit card ka screen kabhi aata hi nahi. Aap tab shuru karte hain jab bill bhejne ka koi raasta hi nahi hota.
  • 🆓 Free tier roughly 1,500 requests/din hai. Ek file padhna = ek request, to personal use mein yeh limit shaayad hi lagti hai.
  • 🛑 Limit paar hone par charge nahi hota, requests ruk jaati hain. Us din standard mode (AI ke bina) chalta rehta hai, aur agle din free tier wapas mil jaata hai.

Jo key aap daalte hain, wo kahan jaati hai

AI mode wale teen tools hamare server se nahi guzarte. Aapki key kahan jaati hai, yeh saaf-saaf likha hai.

ItemAsal mein kya hota hai
Key kahan store hoti haiSirf aapke device par (browser ke localStorage mein). Aapke doosre devices par bhi sync nahi hoti.
Hamara serverHai hi nahi. Na aapki key, na file se padha gaya content — hum kuch receive nahi kar sakte.
Key kahan bheji jaati haiSirf Google ke Gemini API par, aur sirf yeh kehne ke liye ki aapki key se aapki hi file padhi jaaye.
Band karna ho toBrowser data clear karne se key bhi hat jaati hai. Google AI Studio mein key delete karne par wo turant kaam karna band kar deti hai.

3 step mein key lein

Google account hai to iske alawa kuch nahi chahiye.

1Google AI Studio kholein

Niche diye button se Google ka official page (aistudio.google.com) kholein. Yeh Google ka page hai, hamara nahi.

2Apne Google account se sign in karein

Jo Google account aap rozana use karte hain usse sign in karein. Yahan payment details nahi maangi jaati.

3"Create API key" dabayein aur copy karein

"AIza…" se shuru hone wali ek string dikhegi. Use copy karke Dropper ke API key field mein paste kar dein — bas ho gaya.

Google AI Studio kholein ↗

※ Key kisi ko na dikhayein. Agar kisi ne dekh li ho, to AI Studio mein us key ko delete karke nayi bana lein — purani key kaam karna band kar degi.

Aam sawaal aur chintayein

Kya bina pata chale charge ho sakta hai?
Koi credit card save nahi hai, to bill bhejne ka raasta hi nahi hai. Free tier paar hone par charge nahi hota, us din ki requests ruk jaati hain.
Agar meri key chori ho jaaye to?
Key sirf aapke device par hoti hai aur hamare server par kabhi nahi jaati. Phir bhi chinta ho to Google AI Studio mein key delete kar dein — delete karte hi wo kaam karna band kar degi, aur nayi bana sakte hain.
Free tier khatam ho gaya to tool band ho jaayega?
Nahi. Standard mode, jo AI use nahi karta, chalta rehta hai. AI mode ka free tier agle din wapas mil jaata hai.
Confidential documents par use kar sakte hain?
Free tier par, jo aap bhejte hain wo Google ki services improve karne ke liye use ho sakta hai. Confidential documents AI mode mein na daalein (standard mode kuch bahar nahi bhejta).
API key ke bina tool use nahi hoga?
Hoga. Bina key ke standard mode shuru se chalta hai. AI mode un logon ke liye extra option hai jo reading zyada accurate chahte hain.
