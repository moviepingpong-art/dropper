プライバシーポリシー

制定日：2026年7月15日／改定日：2026年7月19日

ドロッパーは、お客様のブラウザ内で動作するツールです。当方はサーバーを保有しておらず、お客様のデータを収集・保存・送信することは一切ありません。

1. 運営者

  • 運営者：Shigeyoshi（個人開発）
  • 連絡先：movie.pingpong@gmail.com

2. 基本方針

ドロッパーはお客様のブラウザ上だけで動作します。読み取った内容やファイルが当方のサーバーへ送られることはありません（当方はサーバーを保有していません）。処理はすべて、お客様ご自身のGoogleアカウントの中で完結します。

3. Googleユーザーデータの取り扱い

ドロッパーは、お客様の許可を得たうえで、以下の権限（スコープ）の範囲でGoogleサービスにアクセスします。

権限利用目的
Googleカレンダーの予定の作成・編集
(calendar.events)		イベント文書や予定表から読み取った予定の情報を、お客様のカレンダーに予定として登録するため。
このアプリが作成したファイルへのアクセス
(drive.file)		イベント文書や予定表の文字読み取り（OCR）と、お客様のGoogleドライブへの保存のため。
アプリ専用のデータ領域
(drive.appdata)		保存先フォルダの情報を記録し、パソコンとスマートフォンなど複数の端末で同じフォルダを使えるようにするため。
  • これらのデータは、すべてお客様ご自身のGoogleアカウント内で処理されます。当方がこれらのデータを受け取ることはありません。
  • drive.file は「このアプリが作成したファイル」だけに限定された権限です。お客様のGoogleドライブ全体を見ることはできません。
  • 文字読み取り（OCR）のために一時的に作成するファイルは、読み取り後ただちに削除します。

4. AI機能（Gemini）について

AI機能を使うと、イベント文書や予定表から読み取った文字、または当該ファイル（PDF・画像）そのものが Google の Gemini（AI）へ送信されます。この機能を使うかどうかは、お客様がお選びいただけます。
  • AIの利用は選択制です。ログイン後に表示される画面で「AIを使う」「AIを使わない」をお選びいただけます。
  • 「AIを使う」を選んだ場合のみ、イベント文書や予定表から読み取った文字、または当該ファイル（PDF・画像）そのものが Google の Gemini API へ送信されます。
  • 送信には、お客様ご自身が取得したAPIキーを使用します。キーはお客様の端末内（ブラウザのlocalStorage）にのみ保存され、当方へ送信されることはありません。
  • Gemini API に送信されたデータの取り扱いは、Google のポリシーに従います。
  • 「AIを使わない」を選んだ場合、外部へ文字が送信されることは一切ありません。

5. データの共有・第三者提供

ドロッパーは、お客様のGoogleユーザーデータを、当方または第三者へ販売・共有・移転することはありません。当方はサーバーを保有しておらず、これらのデータを受け取ること自体がありません。

  • 唯一の例外は、お客様が「AIを使う」を選択した場合です。このときに限り、イベント文書や予定表から読み取った文字、または当該ファイル（PDF・画像）そのものが、お客様ご自身のAPIキーを用いて Google の Gemini API へ送信されます。これはお客様の選択にもとづく、お客様とGoogleの間の直接的な送信であり、当方を経由しません。
  • Gemini API に送信されたデータの取り扱いは、Googleのプライバシーポリシーに従います。
  • 上記以外に、Googleユーザーデータを広告・分析・その他いかなる第三者にも提供することはありません。

6. データの保護

ドロッパーは、お客様のデータを保護するために以下の仕組みを採用しています。

  • すべての通信は暗号化された接続（HTTPS）で行われます。
  • ドロッパーはサーバーを保有しないため、お客様のデータが当方の管理下に保存されることはなく、外部からの侵害の対象になりません。
  • Gemini APIキーおよび設定情報は、お客様の端末内（ブラウザのlocalStorage）にのみ保存され、当方を含む外部へ送信されることはありません。
  • GoogleサービスおよびGemini APIへのアクセスは、いずれもお客様ご自身のGoogleアカウントの認証・認可のもとで行われます。

7. データの保持と削除

ドロッパーはサーバーを保有しないため、お客様のGoogleユーザーデータを当方が保持することはありません。お客様の端末内（ブラウザのlocalStorage）には、次の情報のみが保存されます（当方が参照することはできません）。

  • AI機能を使うかどうかの選択
  • Gemini APIキー（AIを使うことを選んだ場合のみ）
  • 保存先フォルダの情報

これらのデータは、以下の方法でいつでも削除できます。

  • 文字読み取り（OCR）のために一時的に作成するファイルは、読み取り後ただちに削除されます。
  • Googleカレンダーに作成した予定、およびGoogleドライブに保存したイベント文書や予定表は、お客様ご自身が管理し、いつでもGoogleの画面から削除できます（ドロッパー側に削除機能はありません）。
  • 端末内に保存されたAPIキー・設定情報は、ブラウザの設定からいつでも削除できます。
  • ドロッパーのGoogleアカウントへのアクセス権は、Googleアカウントのセキュリティ設定からいつでも取り消せます。

8. 料金について

現時点では無料で提供しており、決済情報の取得・保存は行いません。将来的に有料の機能を提供する場合は、本ポリシーを改訂したうえでお知らせします。

9. Google API Services User Data Policy への準拠

ドロッパーによるGoogleユーザーデータの利用および他アプリへの提供は、Limited Use requirements を含む Google API Services User Data Policy に準拠します。

10. 本ポリシーの変更

本ポリシーの内容を変更する場合は、このページに掲載します。重要な変更がある場合は、ツール上でもお知らせします。

11. アクセス解析について

ドロッパーでは、サービス改善のためにアクセス状況を把握する目的で、以下のツールを利用しています。これらが扱うのはサイトの閲覧に関する統計情報であり、Googleカレンダーやドライブの内容（Googleユーザーデータ）とは無関係です。

  • Google アナリティクス：ページの閲覧数や参照元などの統計を、Cookie を用いて収集します。収集される情報は匿名化された利用統計であり、個人を特定するものではありません。データの取り扱いは Google のプライバシーポリシー に従います。
  • 訪問者カウンター（hits.sh）：ページの表示回数を数えて表示します。Cookie は使用しません。
  • Cookie の利用を望まない場合は、ブラウザの設定で Cookie を無効化するか、Google アナリティクス オプトアウト アドオン をご利用ください。
